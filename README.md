# Funniest Time Machine Warning

A make.fun entry for **Funniest Time Machine Warning Label** — the funniest one-line warning label for a time machine in 120 characters or fewer.

## The entry

> WARNING: Killing your grandfather voids the warranty. Yours.

(60 characters)

## How to run

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt` (the graded artifact) and prints it to stdout.
